# 多模态模块画布

本文定义原生画布的上下文、对话与工具行为。课程读取与快照边界见[规格 0027](specs/0027-course-selection-conversations.md)，旧版绑定边界见[规格 0021](specs/0021-modular-canvas-conversations.md)，存储选择见[对话存储决策](decisions/0019-persistent-scoped-canvas-conversations.md)，使用步骤见[Demo 教程](tutorials/canvas-agent-demo.md)。

## 界面与资料

工具栏、导航、笔盒和纸张设置的布局与交互由[画笔与橡皮](drawing-controls.md)定义。视频的大纲与字幕从视频模块打开，传统播放器保留自己的侧栏。

课程资料按当前课程查询、按课次分组，具有加载、空结果、失败重试和不支持格式反馈。支持类型可以放入画布；大型课程视频引用原文件，通过受认证的 Range 端点播放。外部导入文件进入工作区素材目录，课程和原文件不改写。

## 上下文

新对话读取范围明确显示为「当前课程本地材料」，通过检索、再读取取得证据，不自动加载整门课。服务端从当前课次解析课程，模型不能指定其他课程。旧会话默认保留 selected 范围和手动绑定资料；对象标题栏、素材拖放和资料勾选继续可用。活动绑定使用已保存画布 revision。

| 模态 | 实际输入 |
| --- | --- |
| PDF | 新导入使用分页模块，PDFKit / Poppler 按需提供单页 PNG、原文、UTF-16 范围和文字位置；页面支持平移画布与视觉区域选择，原文及文字位置保留给 AI 上下文，不提供 PDF 文字选择入口。旧 PDF 页面卡片保留。 |
| 文本、知识卡片 | 原始文字、结构块和用户作答；不会自动访问文字内的外部链接。 |
| 视频 | 优先读取绑定时间段的已有字幕。工具可提取最长 180 秒的本地音频交给现有 ASR 池，并缓存真实转录；开启视觉输入后可提取真实视频帧。缺少本地文件、ffmpeg、ASR 或视觉模型时明确降级，不读取完整远程视频。 |
| 手写、图片 | 本地将选区材料与笔迹合成持久 PNG，原素材变化不改变截图；旧版临时裁剪保留兼容读取。不会每次落笔都调用模型。 |

PDF 页缓存保留有限数量的最近页面及正在保存的页面，渲染最长 45 秒、图像边长约 1400 像素。源 PDF 通过已验证的文件描述符交给解析器，翻页不复制整份源文件。页面笔迹及其复制件保留独立页码，翻页不会把同一对象其他页的标注显示或擦除。

## 对话与 Agent

AI 默认收为画布右侧的小入口，可直接拖到屏幕任意位置，松手贴边并展开对话栏；对话栏从停靠一侧短距离滑入、收起时滑出，收起箭头指向离开方向。对话栏是唯一的玻璃层，其中的消息、欢迎卡与输入区为不再模糊的色调面，圆角与外框同心；停靠位置保存在本机。左边停靠时对话栏在左侧，其余位置在右侧。主工具栏不再重复提供「问 AI」；点击悬浮入口时，已有选区可用于提问，无选区则打开对话栏。可查看历史、编辑草稿、检查或移除来源，侧栏显示在停靠工具之上，避免工具按钮遮住对话文字或抢走点击；再次收起后原区域恢复输入。对话切换器可切换已有对话或开始新对话；隐藏期间进行中的回答继续完成。侧栏展开时，已绑定资料与输入区之间的细线显示读取、引用和定位关系，减少动态效果时保持静止。

默认使用矩形框选，边框与截图都采用拖出的范围，不自动贴合对象；自由套索可手动切换。套索或框选后点击「问小 c」或拖拽截图入口到对话输入区，均只向侧栏的同一草稿添加截图。先冻结选择并捕获，再展开侧栏；每次选择生成一张 PNG，多卡片保持相对位置，套索外透明。新截图默认作为附件，不受旧版看图开关控制，每轮最多两张、每张至多 3 MiB。视频纹理由冻结时刻的本地实际帧代替；失败时停止准备。点击发送才调用模型；不能识图时明确失败。截图超出视口或准备时画布改变会中止。上传失败支持用同一份像素重试。

发送前先保存问题；保存失败时问题保留为草稿，不启动模型请求。图片准备期间输入的下一条草稿与当前问题分别保留。准备和保存期间也可停止，已取消的准备任务不继续调用模型。退出画布会中断尚未完成的任务并保存中断状态；侧栏收起不等于退出画布。

对话身份继续由画布中的 `conversation` 对象保存，并通过 `conversation_id` 引用课次目录 `study-conversations/` 中独立的 revision 文件；这些对象不渲染为可拖动卡片，不参与命中或全画布适配，也不改写原位置。记录包含草稿、用户问题、模型回答、来源范围指纹、失败或中断状态，以及回答来源。普通文本回答是正常结果。应用重启后未完成任务显示中断并可重试，不伪装为继续运行。

草稿附件与已发送附件分别存储。发送前保存用户消息和不可变附件引用，再启动模型；保存失败、取消与网络失败保留可重试内容，等待期间的新草稿不被清空。活动对象绑定仍清理失效引用，已保存截图不随翻页、隐藏或删除而移除。新图片从附件端点恢复；旧版 `allow_images` 和 `restoreStudyVisual` 分支单独保留。

模型复用现有 ModelPipeline。历史只包含当前来源集合、范围、内容指纹、原图路径、视觉授权与所附图片摘要完全一致的最近成功轮次；移除或改变来源后，不再提交其依赖历史或旧工具结果。工具清单如下：

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| get_canvas_context | 无 | 截图附件清单、独立的对象来源清单和课程读取范围 |
| search_course_materials | query | 当前课程最多 12 个候选及摘要，不代表已读 |
| read_course_source | source_id, offset, limit | 真实正文、指纹、载体与 rune 定位；最多 12000 字符，提供继续位置 |
| read_document_selection | source_id | 真实文字选区及锚点 |
| get_video_context | source_id | 已有或按需转录的真实时间段内容，或不可用原因 |
| inspect_canvas_region | source_id | 附件的已验证图像/识图结果，或绑定对象的视觉结果；无可用输入时返回 unavailable |

运行状态的 `trace` 每步记录工具名、状态和所读资料的 `source_id`，画布据此显示正在读取的资料；它不改变工具权限。

引用前必须实际读取或观察对应来源。生成内容默认显示在对话内，支持 Markdown、公式、代码和表格。用户点击某条已完成回答的「留在画布」，客户端将该回答复制成带来源的可编辑文字卡片，优先放在来源旁并让卡片进入视野；该操作可撤销，原对话保留。已留在画布的回答改为「已在画布 · 查看」，点击选中该卡片并移到视野中，不会再复制一份。模型不具备创建卡片、修改卡片、连线或自动定位工具。用户点击回答下的来源按钮才定位原资料。单次最多 20 次工具调用、12 轮模型响应、3 次视觉调用；工具任务最长 180 秒。片段解析支持取消，任务最长 150 秒并复用 ASR 的限流策略。

## 来源与恢复

Flutter 保存回答及来源，忽略模型返回的画布操作；手动留在画布使用客户端自己的卡片创建与撤销路径。历史待确认操作不提供执行入口；既有卡片及手写仍可手动编辑、保存和撤销。对话历史、草稿及来源通过独立记录恢复。

课程证据只有在本轮读取且被回答实际引用时进入 `result.citations`，正文编号和末尾来源条共享导航方法。未入画布的材料不伪造对象 ID。来源解析重新验证课程、文件和指纹；已存在的材料复用，缺失时导入，无法精确显示的解析文本使用带原文件来源的摘录卡片。仅完整、唯一的解析块匹配才提供精确页码，rune 偏移不直接用于 UTF-16 文本选择。导航避让侧栏，最多保存 20 个会话内返回位置；返回不删除新卡片或撤回用户编辑，手势中断动画。

旧来源包含工作区与对象 ID、文档 ID/页码、UTF-16 范围、归一化页面区域、笔迹 ID、视频时间和内容指纹。课程资料同时记录原课次和相对文件路径。点击引用可翻到原页、定位区域或跳转视频时间；无法定位时明确提示。画布格式和回退约定见[学习画布](study-canvas.md)。

## 验证边界

Go 验证受限引用、资料和对话隔离、原文件保留、CAS 与升级快照；PDFKit/Poppler 的真实解析测试区别于模型测试。Flutter 验证独立对话恢复、真实选区 PNG、每页笔迹、批次状态、画笔与手势回归。Node 协议 fixture 验证工具循环、资料移除后的历史隔离、视觉降级和取消，不能证明真实模型理解。真实推理需要已配置模型；平板帧率需要在实际设备上测量。
