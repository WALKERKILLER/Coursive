# 多模态模块画布

本文定义原生画布的上下文、对话与工具行为。权限边界见[规格 0021](specs/0021-modular-canvas-conversations.md)，存储选择见[对话存储决策](decisions/0019-persistent-scoped-canvas-conversations.md)，使用步骤见[Demo 教程](tutorials/canvas-agent-demo.md)。

## 界面与资料

工具栏、导航、笔盒和纸张设置的布局与交互由[画笔与橡皮](drawing-controls.md)定义。视频的大纲与字幕从视频模块打开，传统播放器保留自己的侧栏。

课程资料按当前课程查询、按课次分组，具有加载、空结果、失败重试和不支持格式反馈。支持类型可以放入画布；大型课程视频引用原文件，通过受认证的 Range 端点播放。外部导入文件进入工作区素材目录，课程和原文件不改写。

## 上下文

每个对话拥有独立的手动参考资料。对象标题栏的加入对话按钮、引用条拖放、资料勾选与选区问 AI 是授权入口。当前视频和其他未绑定对象不自动读取。发送前上下文预览使用已保存画布 revision；绑定可分别保存文字范围、文档页码和视频时间段。

| 模态 | 实际输入 |
| --- | --- |
| PDF | 新导入使用分页模块，PDFKit / Poppler 按需提供单页 PNG、原文、UTF-16 范围和文字位置；页面支持平移画布与视觉区域选择，原文及文字位置保留给 AI 上下文，不提供 PDF 文字选择入口。旧 PDF 页面卡片保留。 |
| 文本、知识卡片 | 原始文字、结构块和用户作答；不会自动访问文字内的外部链接。 |
| 视频 | 优先读取绑定时间段的已有字幕。工具可提取最长 180 秒的本地音频交给现有 ASR 池，并缓存真实转录；开启视觉输入后可提取真实视频帧。缺少本地文件、ffmpeg、ASR 或视觉模型时明确降级，不读取完整远程视频。 |
| 手写、图片 | 本地裁剪实际选区后按需识图；选区文字/笔迹变化会阻止使用过期的视觉附件。不会每次落笔都调用模型。 |

PDF 页缓存保留有限数量的最近页面及正在保存的页面，渲染最长 45 秒、图像边长约 1400 像素。源 PDF 通过已验证的文件描述符交给解析器，翻页不复制整份源文件。页面笔迹及其复制件保留独立页码，翻页不会把同一对象其他页的标注显示或擦除。

## 对话与 Agent

AI 默认收为画布右侧的小入口，可直接拖到屏幕任意位置，松手贴边并展开对话栏；对话栏从停靠一侧短距离滑入、收起时滑出，收起箭头指向离开方向。对话栏是唯一的玻璃层，其中的消息、欢迎卡与输入区为不再模糊的色调面，圆角与外框同心；停靠位置保存在本机。左边停靠时对话栏在左侧，其余位置在右侧。主工具栏不再重复提供「问 AI」；点击悬浮入口时，已有选区可用于提问，无选区则打开对话栏。可查看历史、编辑草稿、检查或移除来源，侧栏显示在停靠工具之上，避免工具按钮遮住对话文字或抢走点击；再次收起后原区域恢复输入。对话切换器可切换已有对话或开始新对话；隐藏期间进行中的回答继续完成。侧栏展开时，已绑定资料与输入区之间的细线显示读取、引用和定位关系，减少动态效果时保持静止。正在读取的资料卡片边缘有一圈沿边缘流转的彩色光（仿 Apple Intelligence 的边缘光），其连线换成同色渐变，状态文字「正在阅读…」有一道光扫过，减少动态效果时为静止的彩色描边。已绑定资料在「看图」旁排成一行；放不下时收为「N 份资料」，读取中改为「正在读 · 资料名」，点开在输入框上方展开列表，每项显示完整名称、页码或时间段和移除按钮，列表超过约 4 项时滚动；只剩一份资料时恢复成一行。

套索或框选后，选区右上角外 8 dp 出现操作条：「问 AI」「摘录」「关联」，复制、粘贴、副本、旋转、形状、识别手写、筛选、删除与取消选择收在「…」菜单；上方被顶栏遮挡时翻到选区下方，距窗口边缘至少 12 dp，按钮命中区不小于 44 dp。Enter 打开提问，Esc 逐级退回。「问 AI」在原位展开约 360 dp 的输入框，资料条列出每个已绑定来源及其页码、局部或笔画数，并标明是否含可读文字；可逐个移除，「+」从附近卡片中追加。PDF 局部选区按页面真实文字框读取：至少一半落在选区内的词组成连续的 UTF-16 范围，作为来源文字、范围与引文；旋转的卡片和没有文字的局部保持需要看图，不扩大到整页。「看图」默认关闭，关闭时不截图，请求携带空的 visuals；资料都没有可读文字时提示打开「看图」，打开后先预览将要发送的实际裁剪图。侧栏对话在打开「看图」时才截取仍在画布上的同一选区。整张卡片与卡片内区域均绑定真实来源；多卡片分别裁剪，每次最多两张图片，超限明确提示缩小选区或关闭看图，不静默丢弃。空选区不发起请求；截图时选区超出视口或发生变化会停止准备并保留问题，不能静默截掉不可见部分。准备失败在输入框下方持续显示原因并保留问题供重试。回答在侧栏显示，草稿和历史不占据中央画布。

发送前先保存问题；保存失败时问题保留为草稿，不启动模型请求。图片准备期间输入的下一条草稿与当前问题分别保留。准备和保存期间也可停止，已取消的准备任务不继续调用模型。退出画布会中断尚未完成的任务并保存中断状态；侧栏收起不等于退出画布。

对话身份继续由画布中的 `conversation` 对象保存，并通过 `conversation_id` 引用课次目录 `study-conversations/` 中独立的 revision 文件；这些对象不渲染为可拖动卡片，不参与命中或全画布适配，也不改写原位置。记录包含草稿、用户问题、模型回答、来源范围指纹、失败或中断状态，以及回答来源。普通文本回答是正常结果。应用重启后未完成任务显示中断并可重试，不伪装为继续运行。

准备对话资料时，客户端按当前画布清除已删除或已隐藏卡片及笔迹的活动引用，并保存修复后的资料范围。历史回答与来源引用保留。界面提示用户确认剩余资料；若本次发送时才发现失效引用，则保留问题并停止发送，用户确认后可再次发送。重新绑定同一张卡片会替换其旧页码和局部范围，不叠加旧截图；看图开关由绑定资料决定，关闭后重开对话仍可再次启用。清理引用只撤销绑定范围发生变化的临时截图，移除无关视频时间字段不影响 PDF 附图。重新打开对话后，PDF／图片的局部附图按已绑定页面与归一化区域从本地原图恢复，不依赖当前视口；原图不可读或手写截图已失效时保留问题并提示重新选择，不向模型发送缺失的选区。

模型复用现有 ModelPipeline。历史只包含当前来源集合、范围、内容指纹、原图路径、视觉授权与所附图片摘要完全一致的最近成功轮次；移除或改变来源后，不再提交其依赖历史或旧工具结果。工具清单如下：

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| get_canvas_context | 无 | 已绑定资料、实际可用性与来源 |
| read_document_selection | source_id | 真实文字选区及锚点 |
| get_video_context | source_id | 已有或按需转录的真实时间段内容，或不可用原因 |
| inspect_canvas_region | source_id | 真实图像/视觉结果，或 unavailable |

运行状态的 `trace` 每步记录工具名、状态和所读资料的 `source_id`，画布据此显示正在读取的资料；它不改变工具权限。

引用前必须实际读取或观察对应来源。读取工具把文档切成句段、把转录切成带时间的行，并为每段、每行和每次成功看图登记由宿主签发的证据 ID；回答用 `[[e:ID]]` 标注。结束时宿主只保留本轮签发过的标记并删除其余标记，返回 `schema_version: 2`、最多 24 条被引用证据与最多两条下一步建议（回看原文、追问、整理成提纲）。资料中形似标记的文字在交给模型前被中和，历史回放时去掉标记。daemon 保存对话时校验证据的类型、状态、锚点和大小；旧回答继续显示来源按钮。决策见 [ADR 0029](decisions/0029-host-issued-evidence-markers.md)，契约见 [spec 0027](specs/0027-grounded-canvas-answers.md)。

回答中的标记显示为编号角标。指针悬停或键盘聚焦只预览引文，并在画布上高亮实际文字行、区域、笔迹范围或视频卡片，不移动视图；来源在视野外时在最近的窗口边缘显示方向标。触屏轻点先显示预览，再点「定位」。点击角标先校验工作区、对象、可见图层、页面文字、引文、笔迹与时间，失效时提示「来源已失效」或「无法定位」，不移动；有效时记下当前视图（相机、缩放、选择、PDF 页、视频时间、侧栏状态，最多 10 个），再飞到侧栏以外可视区域内的目标，减少动态效果时直接切换；笔、触摸、滚轮或捏合会停止飞行。导航翻页属于阅读状态，不进入撤销；视频跳到核实时间并暂停。「返回原处」、Esc、Alt+← / ⌘[ 与系统返回按后进先出恢复；只有此后没有翻页、播放或拖动视频时，才恢复原页码和原时间。

回答下方显示依据覆盖：原文段数、讲解句数、看图处数与已失效数；没有引用时说明内容可能来自常识或推断。建议只是入口：回看原文直接定位，追问填入输入框等待确认，提纲建议打开「整理提纲」的确认框。生成内容默认显示在对话内，支持 Markdown、公式、代码和表格。用户点击某条已完成回答的「留在画布」，客户端将该回答（不含标记）复制成带被引用来源的可编辑文字卡片，`generation` 为 `canvas-turn:<conversation_id>:<turn_id>`（超过 100 字符时取稳定哈希），优先放在来源右侧、下方或左侧不与卡片和笔迹重叠的位置并让卡片进入视野；该操作可撤销，原对话保留。已留在画布的回答按 generation 找回卡片并改为「已在画布 · 查看」，编辑后仍保持关联，删除后可再次留在画布，不同轮次的相同回答各自留存；早期按文字留下的卡片仅在该回答在对话中唯一时匹配。模型不具备创建卡片、修改卡片、连线或自动定位工具。单次最多 20 次工具调用、12 轮模型响应、3 次视觉调用；工具任务最长 180 秒。片段解析支持取消，任务最长 150 秒并复用 ASR 的限流策略。

「整理提纲」（输入区底部或回答下的建议）先确认要读的来源和是否「看图」，再以 `task: "propose_outline"` 运行：只读已绑定来源、不带历史，返回 OutlineProposal 草案——引用证据的事实、模型的归纳、复习问题、来源冲突和无法解释的手写标记；从未看到的所选笔迹也成为待确认标记，不猜测含义。草案在与 AI 停靠侧相对的审核栏中打开（窄屏为底部面板），不改画布：逐条确认（A）、标为待查（F）、编辑、拆分、合并、拖动或 Alt+↑/↓ 排序、删除与新增，Ctrl/⌘+Z 撤销；手写标记显示原笔迹缩略图，由用户选择已掌握、重点、待复习、自定义或保持原样；失效依据只能保留为待查或移除。草稿存在对话中，切换或重启可恢复。「保存为笔记」以 `outline-<proposal_id>` 写入普通课程笔记，带 base_body 防覆盖，重试不重复，冲突时可另存一份；导出 Markdown 或在本机生成的分页 PDF（A4/Letter、横竖、页边距），未确认内容放入「待核实」附录，来源带页码、时间与 `coursive://` 回链；预览经 `POST /api/export/pdf-preview` 渲染将要保存的同一份字节。契约见 [spec 0028](specs/0028-reviewed-outlines-and-paged-export.md)，导出方案见 [ADR 0030](decisions/0030-on-device-pdf-export-with-an-embedded-font.md)。

## 来源与恢复

Flutter 保存回答及来源，忽略模型返回的画布操作；手动留在画布使用客户端自己的卡片创建与撤销路径。历史待确认操作不提供执行入口；既有卡片及手写仍可手动编辑、保存和撤销。对话历史、草稿及来源通过独立记录恢复。

来源包含工作区与对象 ID、文档 ID/页码、UTF-16 范围、归一化页面区域、笔迹 ID、视频时间和内容指纹。课程资料同时记录原课次和相对文件路径。点击引用可翻到原页、定位区域或跳转视频时间；无法定位时明确提示。画布格式和回退约定见[学习画布](study-canvas.md)。

## 验证边界

Go 验证受限引用、资料和对话隔离、原文件保留、CAS 与升级快照；PDFKit/Poppler 的真实解析测试区别于模型测试。Flutter 验证独立对话恢复、真实选区 PNG、每页笔迹、批次状态、画笔与手势回归。Node 协议 fixture 验证工具循环、资料移除后的历史隔离、视觉降级和取消，不能证明真实模型理解。真实推理需要已配置模型；平板帧率需要在实际设备上测量。 带证据的回答另有：Go 以真实 PDF 验证局部文字范围与看图回退，并拒绝格式错误的证据；Node fixture 验证签发、伪造与越界标记、转录时间、建议上限、历史去标记与资料内注入标记；Flutter 验证操作条位置与键盘、看图关闭时不附图、草稿保留、角标渲染、悬停不移动、导航与返回顺序、手势中止、导航不产生编辑、视频暂停、失效来源与留在画布身份。提纲另有：Go 校验提案格式、笔记幂等与冲突、预览不留文件；Node fixture 验证只保留签发证据、未读笔迹成为标记、40 段与 15 个标记时的大小预算和历史隔离；Flutter 验证审核操作、标记选择、失效依据、保存与冲突、引用往返后焦点回到原条目、窄屏面板，并用 Poppler 检查 PDF 的文字层、目录页码与标题不落在页底。审核栏与 PDF 共用同一套行内切分（`$…$`、`$$…$$`、`\(…\)`、`\[…\]`，价格中的 `$` 保持文字），审核栏把公式排成数学式；PDF 中的公式按其真实基线对齐正文。
