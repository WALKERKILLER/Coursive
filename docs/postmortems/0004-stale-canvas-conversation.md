# 旧对话引用已删除卡片导致资料准备失败

Artifact-Version: 1

## Executive summary

活动对话引用未随画布卡片删除而更新，导致完整画布仍无法准备 AI 资料。

## Summary

画布正常加载，但对话恢复的 `query.objects` 包含不在当前画布中的卡片 ID，资料接口返回 400「无效的学习画布」。显示画布和读取对话各自成功，因此仅检查文件完整性不能发现这个跨文件引用问题。去掉失效 ID 后，同一接口返回有效资料；问题不涉及课程文件丢失。

## Timeline

2026-11-07：用户报告对话区错误；本机复现原查询返回 400，过滤不存在的卡片 ID 后返回有效资料。

## Root cause

活动查询与画布分开持久化，删除卡片或笔迹后，恢复对话仍直接使用旧 ID。客户端刷新了画布版本号，却没有协调查询中的对象与笔迹引用，触发后端的严格范围校验。

客户端在准备资料前协调当前可见卡片、笔迹与活动查询，持久化修复结果并提示用户。历史消息保留；发送过程中发生引用变化时保留草稿、停止本次发送，避免悄悄改变提问依据。后端继续严格校验资料范围。

## Guardrails

[回归测试](../../app/test/study_query_test.dart)通过真实对话组件恢复含失效引用的记录，验证有效资料、草稿、持久化修复和不自动发送。手势阈值的单独调整由现有卡片输入、视频、压感橡皮和防误触测试覆盖。
