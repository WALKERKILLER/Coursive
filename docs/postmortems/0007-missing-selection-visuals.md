# Missing PDF selection images

Artifact-Version: 1

## Executive summary

PDF 选区对话保留了页码、范围和看图开关，但没有恢复临时图像；无关查询字段的清理也会清空刚生成的截图。模型因此收到无法读取的选区。

## Summary

界面显示已绑定 PDF 第 4 页且开启看图，模型的视觉工具返回 unavailable。用户无法通过再次发送恢复图像。

## Timeline

2026-11-07：从设备中的失败对话确认局部区域与本地页面图像均有效；发现对话临时截图的生命周期和绑定清理不一致。关闭恢复逻辑后，重新打开离屏 PDF 选区的组件回归测试失败。

## Root cause

对话持久化查询与 allow_images，但 visuals 只在组件内存中。后端为防止越过用户授权的局部范围，拒绝用整页图片替代缺失截图。另一个入口在清除无关视频时间字段时将全部临时截图清空。先前真实模型检查手动附带图像，未覆盖组件重开和查询清理路径。

## Guardrails

[选区恢复测试](../../app/test/study_visual_restore_test.dart)通过真实对话组件验证重开、离屏裁剪、读取失败保留草稿、重试和准备中退出；像素断言验证只发送批准范围，包含旋转后的坐标。来源指纹包含页码、区域与图像路径，避免扫描件空文本哈希相同造成错误复用。查询清理仅撤销绑定发生变化的截图；无法恢复的纯笔迹要求重新圈选，不发送空的视觉请求。

## Follow-up audit

对相邻状态转换的复查发现，看图开关曾依赖临时图片是否存在，导致关闭后重开无法启用；等待图片时清空输入也会丢失新草稿。回归测试分别重现这两个问题。绑定替换、取消后重试、撤销附图权限、移除来源、空套索、PDF 页脚及图片卡片留白也纳入验证。历史作用域包含视觉授权和实际图片摘要，避免使用已撤销或换图前的回答。笔迹 fixture 按真实来源 ID 返回上下文，防止测试在后端本会拒绝的附件上误报成功。

后端会在读取会话时补齐值为 0 的视频时间字段；客户端曾把这些无作用域的默认值当作引用变化，重开 PDF 会话也显示修复警告。[查询协调测试](../../app/test/study_query_test.dart)验证这种真实序列化形态保持稳定，同时继续撤销被删除或隐藏视频的非零时间范围。
