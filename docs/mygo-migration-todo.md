# Coursive MyGo 迁移实施清单

本清单配合[迁移规格](specs/0033-mygo-client-migration.md)使用。源码基线为上游 `dev` 的 `bfc7ec8`。链接定位基线行号，文件改动后按旁边的符号查找。新增的客户端目录为 `app-mygo/`。以下任务按依赖排列，每项末尾给出完成时应留下的证据。

原型阶段可并行验证。P01 先跑通桌面与 Android，签名 iPad 的本地服务依赖 P04。实现阶段先完成 S01、S02，再并行推进业务页面与播放。C03 是画布写入前置条件，C04、C05 和 C06 依次接通坐标、触摸和触笔，C07 在保存和输入稳定后验收。R03 依赖现有功能齐套及同步验收，R04 按平台放行。

## Linux 桌面进度

按文件对照，`app-mygo/` 已移植 Flutter 客户端在桌面上的页面、流程和设计系统，并在 Linux 上连接真实 daemon 运行。下面的条目仍未勾选，因为各自要求的设备、样本和验收记录还没有补齐。已知缺口：

- Android 首次运行的工作区安装（[`WorkspaceSetupPage`](../app/lib/features/setup/workspace_setup_page.dart)）随 Android 构建移植。桌面不会进入这一步。
- MyGo 客户端还没有桥接的系统 WebView。插件的 web-ui 页面在 macOS 和 Android 上回退为原生说明页，Flutter 客户端在这两个平台上会渲染它。Linux 和 Windows 上 daemon 本身就不放行，两个客户端都回退。
- Linux 视频经系统 GStreamer 播放，需要 `gst-plugins-good` 等插件包，清单见 [app-mygo/README.md](../app-mygo/README.md#video-on-linux)。Flutter 客户端自带 libmpv，没有这项系统依赖。
- 动效按 Flutter 对照：`AnimatedSwitcher` 统一走 `design.Switcher`（新旧内容同时进出，出场曲线反向），`TabBarView` 走 `m3.TabView`（横向滑动），隐式动画缺省为线性。`m3` 的墨水层照 `InkWell` 画在子元素下面（不透明的封面不会被悬停、按压染色），悬停与聚焦 50ms、按压 200ms 叠加淡入，按压波纹照 `InkSparkle`：617ms 跑完、松手不打断、柔边圆从按点漂向中心，闪点颗粒由 `m3/sparkle.go` 把 `ink_sparkle.frag` 移植成 `ui/shader` 着色器画出。菜单照 Flutter 分两种：`MenuAnchor` 不带 `animated`，`m3.Menu` 缺省也即开即关；`PopupMenuButton` 和 `showMenu` 的菜单加 `m3.Popup`，300ms 从顶端一角展开、各项依次淡入，关闭时 MyGo 的退场副本不能裁剪，只按折叠露出的多少淡出。其余组件照各自源码：输入框的标签与边框 167ms，错误提示从上方四分之一处滑入并与帮助文字交叉淡入；纸片的选中色 195ms、勾选位置 150ms 展开、勾号逐笔画出，墨水同 `ListTile` 一样取主题色而不是状态层；分段按钮直接换色；Snackbar 从底边展开、在 `Interval(.4, .6)` 里显出，消失时原高淡出，下一条等上一条走完；提示、对话框、底部面板退场沿原曲线倒回；进度条只有 Flutter 包了 `TweenAnimationBuilder` 的地方带 `Progress.Motion`。顶栏滚动后的着色即时切换；`ExpansionTile` 用同一个 200ms 控制器经 `easeIn` 转箭头、染图标、从中间展开内容；滑块按下即变窄，轨道间隙从中心量 6；日期选择器按月横向滑动，时间表盘的指针走近路。标签栏的文字颜色随指示器 300ms 在新旧两项间交叉渐变，墨水取 `_TabsPrimaryDefaultsM课程封面的 Hero 照 `MaterialRectArcTween` 沿弧线飞（`m3.Hero`）；列表和滚动区的 `ensureVisible` 用 `app/reveal.go` 先跳到行再按对齐方式带动画滚动；`m3.TabView` 照 `PageScrollPhysics` 跟手滑动、按弹簧吸附，标签栏指示器同步跟随，鼠标拖动与 Flutter 一样不换页；开关可拖动拇指，过半松手即切换；提示照 `RawTooltip` 悬停 500ms 显示、离开 100ms 后消失，触摸长按显示 1.5s。底栏 `AnimatedSwitcher` 居中时的布局怪癖没有照抄。le.ensureVisible` 的滚动在这里是跳转；`m3.TabView` 还不能手势滑动换页。
- 阴影按 Flutter 对照：`Material` 的 elevation 走 `m3.Elevation`，自绘的 `Canvas.drawShadow` 走 `m3.PaintElevation`，两者都用两层盒阴影拟合 Flutter 的物理阴影；`BoxShadow` 的 `blurRadius` 用 `design.BoxShadowBlur` 换算，`MaskFilter.blur` 的 sigma 乘 2。
- 布局按 Flutter 对照：MyGo 的 `ui.ButtonBase`（`m3.Tappable` 也是）缺省是居中的行（`Row().Center()`），`InkWell` 没有这层居中。照 `InkWell` 移植的列表行和卡片要写明 `Justify(ui.Start)`，改成列的还要写 `AlignItems`。`AlignItems(ui.Center)` 的列会把 `m3.Field` 缩到 200px，而 Flutter 的 `TextField` 总是占满宽度，这时只让需要居中的子元素 `AlignSelf(ui.Center)`。

## 0．先验证四条高风险路径

- [ ] **P01 签名构建并连接真实 daemon。** 新客户端先实现一个课程列表。用 [`DaemonService._launch`](https://github.com/WALKERKILLER/Coursive/blob/bfc7ec84e9cdbaa6783adb0c8cc301dd8188fe47/app/lib/core/daemon_service.dart#L157) 对照启动握手，用 [`Api._send` 和 `Api.sse`](https://github.com/WALKERKILLER/Coursive/blob/bfc7ec84e9cdbaa6783adb0c8cc301dd8188fe47/app/lib/core/api.dart#L83) 对照请求与事件。先验证 Linux、Android 手写平板和签名 iPad。iPad 的本地核心由 P04 验证。证据为锁定版本、设备、启动耗时、课程列表和事件恢复记录。
- [ ] **P02 验证 Mayu。** 固定规格中列出的 Mayu 提交与 MyGo v0.10.0，编译课程列表、对话框和带中文输入法的表单。以 [`buildScheme` / `buildTheme`](../app/lib/theme/theme.dart) 为视觉对照，并且是逐令牌对照而不是目测：间距、圆角、页面内边距、断点与默认种子色由解析 [`tokens.dart`](../app/lib/theme/tokens.dart) 的测试比对，色板取 Flutter 自己生成的 `ColorScheme` 而不是重新生成。证据为三端构建、浅深色截图与两端截图差异测量、中文候选确认、键盘焦点和读屏结果；评估升级 Mayu 的改动量后决定采用范围。
- [ ] **P03 验证触笔与视频合成。** 在同一画布放视频卡片、PDF 卡片和笔迹覆盖层。沿 [`StudyCanvasState._videoInput`](https://github.com/WALKERKILLER/Coursive/blob/bfc7ec84e9cdbaa6783adb0c8cc301dd8188fe47/app/lib/features/study_canvas/study_canvas.dart#L1195) 和 [`VideoCardHoldRegion`](../app/lib/features/player/video_card_hold.dart) 复现跨卡片双指操作；沿 [`StylusBridge.touch` / `generic`](https://github.com/WALKERKILLER/Coursive/blob/bfc7ec84e9cdbaa6783adb0c8cc301dd8188fe47/app/android/app/src/main/kotlin/io/github/walkerkiller/coursive/StylusBridge.kt#L83) 核对输入字段。Android 与 iPad 分别记录笔、手指、取消和压力事件。证据为脱敏事件用例、叠墨录屏、性能基线和框架缺口清单。
- [ ] **P04 验证 iOS 应用内核心。** 从 [daemon `run`](https://github.com/WALKERKILLER/Coursive/blob/bfc7ec84e9cdbaa6783adb0c8cc301dd8188fe47/daemon/cmd/coursive-daemon/main.go#L134) 梳理信号处理、路径、服务注册和子进程依赖，用最小样本验证沙盒内打开课程库、SQLite/FTS、读写画布和前后台恢复。证据为签名真机结果与能力表，逐项注明本地可用、需要替代或延后。

P03 若无法保住真实笔迹和取消语义，Android 继续使用 Flutter 发布。P04 结果决定 iOS 本地首版是否进入排期。

## 3．功能齐套、发布与回退
