# 小 C 的全局记忆和课程记忆

## Status
Accepted
Class: feature

## Context and Problem Statement

学生会换模型，或在同一课程里另开对话。全局档案已有学习背景和偏好。伴学原来按会话保存计划、作答和来源。

## Decision Drivers

学生能续做同一道题，每门课各记各的进度。教师讲解和旁问不计作学生的答案。

## Considered Options

- 将聊天摘要作为唯一的课程记录。
- 在课程记忆中保存可读摘要，由伴学插件另存可恢复的学习记录。

## Decision Outcome

课程会话读取全局背景、偏好和当前课的 Markdown 记忆。学生可通过已有记忆工具维护课程记录，后台整理遵守自动整理开关。伴学插件在自己的工作目录按课程保存计划和作答，打开同课会话时从保存点继续。

旁问保留在对话里。选择题要收到学生的选项才计分，简答要保留原回答和判据。插件工作目录内的进度分支各自引用上一份保存点。课程记忆 Markdown 的冲突按资料同步规则处理。按课程筛选的交换目录只交换所选课程范围内的资料。

## Pros and Cons of the Options

聊天摘要简短，无法据此还原一道待答题或核对判分。保存学习记录可以重建计划和作答，也会增加本地存储。只向模型自动提供简短摘要，按需读题目和材料。
