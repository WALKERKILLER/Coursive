# 小 C 的全局记忆和课程记忆

## Status
Accepted
Class: feature

## Context and Problem Statement

学生会换模型，或在同一课程里另开对话。全局档案已有学习背景和偏好。伴学原来按会话保存计划、作答和来源。

## Decision Drivers

学生能续做同一道题，每门课各记各的进度。教师讲解和旁问不计作学生的答案。

## Considered Options

- 将聊天摘要作为唯一的课程记录。
- 在课程记忆中保存可读摘要，由伴学插件另存可恢复的学习记录。

## Decision Outcome

采用第二种方案。课程会话从常驻助手读取全局背景、偏好和当前课的 Markdown。插件在个人资料库工作目录下按课程 ID 保存计划变更。新会话从同课记录恢复进度。宿主把已保存进度的摘要写入当前课程记忆，只更新伴学段落。明确的伴学操作触发保存；背景整理仍遵守原有的自动整理开关。

旁问保留在对话里。选择题要收到学生的选项才计分，简答要保留原回答和判据。多个设备离线修改同一份进度时，各变更分别引用原进度。同步后学生能选择要继续的分支。使用按课程筛选的交换目录时，还需把插件工作目录纳入设备同步。

## Pros and Cons of the Options

聊天摘要简短，无法据此还原一道待答题或核对判分。保存学习记录可以重建计划和作答，也会增加本地存储。只向模型自动提供简短摘要，按需读题目和材料。
