# Brand assets

Every file here except `source/` is generated by [scripts/export-brand-icons.sh](../../scripts/export-brand-icons.sh) from `source/coursive-logo-4096.png`, a full-bleed 4096 × 4096 sRGB image. Regenerate instead of editing an export; [exports.json](exports.json) records the master's hash and every export, and CI rejects a stale or hand-edited set.

## Logo

| File | Use |
|---|---|
| `logo/coursive-square-{128,256,512,1024}.png` | Full-bleed, opaque: stores and places that apply their own mask |
| `logo/coursive-rounded-{128,256,512,1024}.png` | Rounded square on transparency: README, docs, websites |
| `logo/coursive-mark-1024.png` | The gradient mark alone on transparency |
| `logo/coursive-mark-white-1024.png`, `logo/coursive-mark-ink-1024.png` | One-colour marks for dark and light surfaces |
| `social/coursive-social-1280x640.png` | GitHub social preview and README banner |

## Platforms

Paths under `platforms/` mirror where each file goes in the Flutter project:

| Directory | Destination | Contents |
|---|---|---|
| `android/res/` | `app/android/app/src/main/res/` | Legacy and round launcher icons, adaptive background and foreground layers (art fills the 72 dp viewport of the 108 dp canvas), a themed-icon monochrome layer, and the `mipmap-anydpi-v26` XML |
| `android/play-store-512.png` | Play Console listing | Full-bleed 512 px icon |
| `ios/AppIcon.appiconset/` | `app/ios/Runner/Assets.xcassets/` | One opaque 1024 px icon; the system applies the mask |
| `macos/AppIcon.appiconset/` | `app/macos/Runner/Assets.xcassets/` | 824 px body on a 1024 px canvas with a shadow, at every size the asset catalog lists |
| `windows/app_icon.ico` | `app/windows/runner/resources/` | 16 to 256 px |
| `linux/hicolor/` | `share/icons/hicolor/` in packages | 16 to 512 px, named `coursive.png` |
| `web/` | `app/web/` | `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, manifest icons and maskable icons (art fills the 80% safe zone) |

The READMEs reference the banner as `coursive-social-1280x640.png?v=<first 8 hex of its SHA-256>` so browsers and GitHub's image cache fetch a changed banner; update the suffix whenever the banner changes (CI checks it). The social preview is uploaded by hand in the repository settings under **Social preview**.
